# Everthread — Places with a purpose

Prepared for Mavyy and Coding Yuki. Version 1.0, September 17, 2026.

Open `index.html` after extracting the complete ZIP. It is an offline design preview, with a location picker and sample popups. Start with the music studio: tap the producer’s desk or the recording booth. `review/overview.png` is a quick visual introduction.

Included: 25 illustrated location backgrounds, 19 reusable transparent PNG props, 76 object interaction groups, 142 action definitions, 76 SVG hotspot guides, 17 SVG UI assets, an offline review prototype, and implementation documentation.

This is an art and design handoff. It does not patch the game, load saves, implement gameplay, or certify a new game build. Do not rename this ZIP to `everthread-source.zip` or feed it into the source importer.

Read in order:

1. `docs/START-HERE.md` — package tour and scope.
2. `docs/IMPLEMENTATION.md` — router, state, input, and engine contracts.
3. `docs/LOCATION-BLUEPRINTS.md` — every location and its object menus.
4. `docs/ACTION-MAP.md` — bindings, gates and source references.
5. `docs/QA-HANDOFF.md` — completed checks and integration acceptance criteria.

The local preview browser was blocked by session policy. Static compositions and asset integrity were reviewed; the browser walkthrough remains pending. Open the HTML locally in a desktop browser to review interaction behavior. Sample prices, people, products and records are illustrative only.
